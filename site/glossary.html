Glossary

Plain-English definitions for every term this handbook uses. No jargon walls, no condescension — if a word here still feels fuzzy, it's a bug in this glossary, not in you.

Archive (folder) The "keep forever, rarely open" home: tax records, contracts, insurance letters, ID scans. Lives at Filing/Archive. You visit it yearly or in a panic — not weekly. See Chapter 3.

Catch-all box (aka Inbox-unsorted) One guilt-free folder where uncertain files go instead of being agonized over. Its job is to make postponement structured rather than chaotic. Any file you can't decide in five seconds belongs here. See Chapter 2 .

Desktop The file layer that is always visible on screen — which is why it fills. "Tidy Desktop" means one to six current files, not zero. See Chapter 1 .

Downloads The browser's default landing pad. A conveyor belt, not a shelf: it fills itself, invisibly, forever. Nothing in Downloads is "filed" — it's "still landing." See Chapter 1.

Duplicate files Two copies of the same thing, usually born as photo (1).jpg, -copy.docx, or a re-downloaded installer. Rule: keep the newest or the original, trash the rest — never delete from Archive on name alone. See Chapter 5.

Executive function Your brain's project management: starting tasks, holding steps in mind, and closing them out. Filing one download costs three units of it. A folder system for ADHD brains is a system that spends less executive function per file, not a system that requires more willpower.

Guilt-free postponement The design principle behind the catch-all: a decisive "later" beats a perfect "now." The mess comes from chaotic postponement (file lands wherever it lands); the fix is structured postponement (it lands in one known box with a scheduled re-look).

Installers .exe / .msi / .dmg / .pkg / .zip-wrapped programs. Single-use wrappers: once the app is installed, the installer has finished its only job and is safe to delete. The exceptions (no-longer-downloadable or system-recovery media) belong in Archive, not Downloads. See Chapter 5 .

ISO date format (YYYY-MM-DD) Writing dates year-first so they sort chronologically everywhere: 2026-10-14 sorts before 2026-11-02 in every file system and reads unambiguously. The only date format worth putting in filenames. See Chapter 4.

Local AI (local LLM) A language model running on your machine, with documents never leaving your laptop — the Private version of "AI help." Honest role in this handbook: reading assistant and suggestion-maker, not deleter. See Chapter 7.

One-decision rule A triage question that requires exactly one yes/no answer, asked in a fixed order, so sorting never becomes per-file deliberation. The six gates are the backbone of the Decision Card.

Projects (folder) The "action soon" home: files with a deadline or a next step. Lived-in and dated — files graduate to Reference or Archive once their action completes. See Chapter 3.

Reference (folder) The "findable later" home: manuals, insurance letters, recipes, how-tos. For anything you'd search for. Naming rule: name files by what you'll type in the Search box. See Chapter 4.

Reset Day The weekly ten-minute ritual: Desktop to near-zero, Downloads swept oldest- first, installers killed, keepers renamed and housed, catch-all chipped, trash emptied. The Checklist is the step-by-step; Chapter 2 is the why.

Rescue Plan The heavier-armor version of Reset Day for when the mess has reached hundreds or thousands of files: sort by category (type first, then date), clear the installer mountain first, sweep images by month, do documents last. 30–45 minutes a day, not more. See Chapter 6.

Safety buffer / snapshot A temporary copy of files you're about to bulk-delete, parked in a dated folder (Inbox-unsorted/...-...) so bold moves are reversible by recovery rather than regret. Deleted after a quiet week. See Chapter 6 and Chapter 7.

Triage The in-the-moment act of asking one gate's question and sending a file to exactly one of five destinations: Reference, Projects, Archive, Trash, or the catch-all. If a triage session ever involves studying a file, the system has already failed you — send it to the catch-all and move on.

Tidal inundation What we call the point where a file pile stops being countable and starts being weather: opening the folder creates distress instead of progress, so you open it less, so it grows faster. Escaping it always means the same thing: sort by category, not by file. See Chapter 6.
