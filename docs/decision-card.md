# The Decision Card

One page. Six gates, in order. Stop at the first Yes.

Print this, pin it, keep it open during reset day. Full reasoning lives in
[Chapter 3](03-one-decision-triage.md).

---

## The Six Gates (ask in order, stop at first Yes)

| # | One question | If YES → |
| --- | --- | --- |
| 1 | **Is it obviously junk?** (dead screenshots, scanned tickets, mystery `.tmp`) | 🗑 Trash |
| 2 | **Have I already gotten everything out of it?** (installer already run, ticket scanned, form printed) | 🗑 Trash *(rare no-longer-downloadable installers → 🗄 Archive)* |
| 3 | **Do I need to find this later?** | 📚 `Filing/Reference` |
| 4 | **Does something happen with this soon?** (a deadline, an action) | 🛠 `Filing/Projects` |
| 5 | **Must I keep it but rarely open it?** (taxes, contracts, IDs, insurance) | 🗄 `Filing/Archive` |
| 6 | *(None of the above / still unsure)* | 📥 `Inbox-unsorted` — **no guilt** |

## The one-line version

> **Trash what's replaceable. Reference what you'll search.
> Project what's urgent. Archive what's rare-but-required.
> Inbox whatever stalls you.**

## Speed rules while sorting

- **Never open a file to decide.** Name, type, size, date tell you almost
  everything. Stalled > 5 seconds → Gate 6.
- **Sorted by type beats file-by-file.** All installers judged at once, all
  screenshots at once.
- **Sort Downloads oldest first** — old files decide themselves fastest.
- **Dates in filenames** (`2026-10-14`, `due-2026-11-04`) — search will thank you.

## Never-do list (the safety rails)

- ❌ Never delete from `Archive` based on filename alone.
- ❌ Never delete your only cloud copy *and* local copy in the same pass.
- ❌ Never let an AI or script bulk-delete without a safety buffer
  (`Inbox-unsorted` or a snapshot copy).
- ❌ Never chase "perfectly sorted" — a fear-free folder beats a museum.

## Suggested folder skeleton (one place, once)

```
Documents/
├── Filing/
│   ├── Reference/     ← look-it-up-later stuff
│   ├── Projects/      ← open, dated, actionable stuff
│   └── Archive/       ← keep-forever, rarely-opened stuff
└── Inbox-unsorted/    ← the guilt-free catch-all
```
